01裸模型THE BARE LOOP

一个输入，
一片输出。

LLM 给出的不是一个确定的答案，而是一片可能的输出。我们看到的回答，只是从概率分布里采出的一条样本。

  • A同一个 prompt，不保证同一个答案重跑一次、换个温度，就可能走出完全不同的轨迹。
  • B一条真实路径，背后是无数岔路模型只把其中一条，交到了你手里。
只靠“更明确的指令 + 更强的模型”，并不足以换来可交付的确定性。
02为什么会发散ENTROPY SOURCES

发散，
是默认状态。

难任务拉长推理链，弱模型留下更多自由决策点，缺失的工具与信息让模型用猜测填补空白。每一步，都在复制分叉。

  • 01复杂任务 → 解空间膨胀目标越远，中间步骤越多，可能的路径就越多。
  • 02弱模型 → 过多 slots、噪音每个可自由选择的决策点，都会成为误差入口。
  • 03缺工具 / 信息 → 幻觉与噪音模型不知道，就会用一个“听起来合理”的答案补上。
分支不是相加，而是相乘：复杂 × 多轮 × 无验证 ≈ 不可复现。
03HarnessTHE FIXTURE

给概率，
套上夹具。

Harness 是模型之外的约束与反馈系统。它不替模型思考，而是决定哪些输出可以留下、哪些必须重来。

  • ↓减少 slots把本可确定的步骤交给代码、工具和流程，而不是每次都让模型自由选择。
  • ↓降低噪音补上可靠的上下文，用工具获取事实，用验证器发现错误。
  • ↓收束发散把“可能的回答”夹进一个可验收的输出空间。
“这条蓝线，让回答在它之内。”
04多轮RECURSIVE DRIFT

上一轮的错，
进入下一轮。

多轮不会自动纠偏。错误假设、模糊措辞、无效的工具结果，都会成为下一轮的上下文。

  • 01output → new input上一轮答案，成为下一轮前提。
  • 02更复杂的 input，更嘈杂的 output问题、历史与噪音一起进入上下文。
  • 03每个交接点，都是约束点不在交接处重新夹紧，误差就会递归扩大。
发散的轨迹 + 多轮传递 = 指数级失控。
05学习信号REWARD BOUNDARY

边界，
也是奖励。

在训练与评测中，harness 是一道可验证的接受边界：好答案落在界内，坏答案落在界外。保留、修正，再学习。

  • +1夹具内 → Good answer被接受，进入下一轮，也可以被强化。
  • −1夹具外 → Bad answer被拒绝或修复，重新采样。
  • ↻学习 / 多轮规则、测试、人类偏好、Verifier 都可以提供信号。
“Good answer 在夹具内；bad answer 在夹具外。”

约束可以只用于推理时的校验；在 RL / 偏好学习中，它也会成为训练信号。

06生产化 AgentPRODUCTION DETERMINISM

夹得越稳，
越敢放手。

生产级 Agent 把“自由生成”改造成“受控执行”：看见什么、能做什么、怎样算通过、何时交还给人，都有明确边界。

  • 01上下文它看见哪些可靠事实。
  • 02工具 / 权限它能执行哪些动作，最坏能坏到哪里。
  • 03状态 / 反馈它何时继续、何时停止、何时让人接管。
极强的夹具力度 → 生产确定性。

AgentScope / LangGraph 提供状态、工具与流程的抓手；完整的 harness 还需要测试、权限与治理。

07收束SYNTHESIS

模型定上限，
约束定下限。

把 LLM 的概率能力，装进一个可观察、可验证、可回退的系统。不是训练更会思考的模型，而是设计让模型持续做对的工程。

  • CContext让它看见。
  • TTools & Policy让它行动。
  • VVerifier让它知道错了。
  • SState & Governance让流程可控。
人类掌舵，智能体执行。

从草图到概念

读图

笔记的核心不是某一种 prompt 技巧，而是一个几何直觉：LLM 的输出是一个有宽度的空间；Harness 是从外部压下来的边界，让“可能的回答”收束成“可验收的回答”。

笔记继续把这条思路推到多轮、强化学习与生产化 Agent：每一轮都会把噪声带进下一轮，强夹具则换来生产确定性。

概念对照

slots
可自由选择的决策点。每一步的自由度越多，可能路径就越多。
夹具 / harness
模型之外的约束与反馈系统：上下文、工具与权限、验证器、状态编排、治理。不是只等于一个 guardrail。
Good / Bad
落在接受边界内外的输出。把边界作为评测或学习信号，是 RL / 偏好学习的一种用法，并非所有 harness 都会直接训练模型。
AgentScope / LangGraph
两者提供 Agent 编排、状态与工具等基础设施，是 harness 的编排抓手，而不是 harness 的全部。

这次演示扩充了什么

  • 把输出发散拆成三个来源：任务复杂度、模型能力、信息与工具缺失。
  • 把单轮夹具延伸为多轮交接处的重新收紧。
  • 把夹具同时解释为生产约束与可学习信号。
  • 补充“夹具不是越紧越好”的张力：约束要足够，也要保留必要的探索空间。
