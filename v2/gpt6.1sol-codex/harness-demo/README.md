# Harness Engineering · 从发散到可靠

基于 `origin.jpg` 手绘图制作的中文 HTML 交互演示，以一张持续变化的 LLM 输入输出图为中心。

直接用浏览器打开 `dist/index.html` 即可使用。没有构建步骤、依赖安装或外部字体请求，可离线运行。`dist/origin.jpg` 用于原图对照。

六章内容：一次生成、输出发散、运行时轨道、验证与反馈、训练与 Harness、走向生产。

交互：左右方向键切换章节，空格自动演示；复杂度滑块；五种运行时机制开关；五步修复任务模拟；训练与运行时切换；概念训练动画；演示模式；原图与参考资料。

动画是概念示意，不调用真实模型、工具或训练服务。路径宽度不代表实测误差或概率。资料链接和对原图的概念补充位于页面「原图与参考」。

本地服务（可选）：在本目录运行 `python3 -m http.server 8765 --directory dist`，访问 `http://localhost:8765`。
