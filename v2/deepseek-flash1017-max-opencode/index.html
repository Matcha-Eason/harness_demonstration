01OUTPUT DISTRIBUTION/ 输出是一片分布

同一个输入，
长出一片回答

LLM 给出的是候选分布，而不是唯一答案。一次采样，只取走其中一个点。

02NOISE SOURCES/ 发散从哪里来

发散，通常不是单点故障

输入、模型、环境，都会把噪音注入同一条生成链。三类误差可以叠加。

03THE HARNESS/ 装上一副夹具

把发散，夹进可交付的边界

Harness 不改变模型，它改变输出的分布。约束越清晰，交付越可重复。

04COMPOUNDING TURNS/ 多轮会复利

多轮不是加法，
是复利

更复杂的 input → 更噪音的 output；没有夹具，误差会迭代扩大。

05LEARNING SIGNAL/ 边界变成奖励

边界清楚，
反馈才能学习

夹具内 = good answer；夹具外 = bad answer。可判定的差异，才是可学习的信号。

06PRODUCTION/ 生产确定性

极强的夹具力度
→ 生产确定性

不是每次逐字相同，而是行为可预测、可验证、可回滚。

07PRINCIPLE/ 约束让能力可交付

约束，不是让 AI 变弱；
是让能力可交付。

CONCEPT NOTES / 概念注记

从手绘笔记，到一副可运行的夹具

这张手稿的核心不是“更强的模型”，而是模型之外的控制面：输入被整形、输出被夹持、错误被反馈、行为可复现。下面是几处保留与扩写。

  • 01

    slots / 候选槽位

    手稿中“过多 slots、噪音”，这里保留为候选槽位 / 候选空间：模型可自由填充的位置越多，输出越容易漂移。夹具收紧候选，而不是替模型思考。

  • 02

    夹具内 / 夹具外

    把 good answer 留在夹具内、bad answer 落到夹具外，差异就变成可判定的信号。它同时支撑评测、奖励、重试、门禁与 RL；这也是第五章“反馈才可学习”的来源。

  • 03

    信息空间 × 交互时间

    手稿用这组坐标观察多轮行为。演示把它做成行为轨迹：无 harness 的轨迹发散并离开可交付带；有 harness 的轨迹在每一轮被重新夹住。红线写着“real output：被夹住”。

  • 04

    Agentscape → AgentScope

    手稿写作“Agentscape”，按常见生态应指 AgentScope。它与 LangGraph 都是编排底座；Harness 是更上层的可靠性约束，不是它们的替代品。

  • 05

    生产确定性

    “极强的夹具力度 → 生产确定性”不是保证逐字相同，而是让行为可预测、可验证、可回滚。结构化、验证、重试、追踪，是把夹具拧到生产级的具体施力点。

  • 06

    扩充：四类护栏

    公开资料常把 harness 拆成上下文工程、架构约束、反馈回路、熵管理。演示用“输入整形 / 输出夹持 / 反馈闭环 / 运行边界”四项呼应，并把“约束”放在舞台中央。
