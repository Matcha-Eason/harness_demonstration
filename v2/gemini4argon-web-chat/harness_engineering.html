为什么业界都在提 Harness Engineering？

调研核对

在 AI 工程实践中，Prompt 工程仅作用于输入端（左端），而 Harness Engineering（夹具/挽具工程）则是环绕在 LLM 四周的全套确定性控制层——通过类型约束、状态机、沙箱验证和上下文压缩，将高熵的概率生成模型夹紧在工程可交付的轨道内。

1. LangGraph (图状态机强夹具) 手稿左下角点名

用有向状态图（StateGraph）和 TypedDict Schema 锁死节点转移边界。不让 LLM 自由决定任意工作流走向，而是只允许在预定义边（Edges）内做有限路由决断。

2. AgentScope (企业级 Harness 控制面) 手稿左下角点名

通过 AgentScope Harness Runtime 将「大脑推理 (Brain)」与「受控工具沙箱执行 (Hands)」解耦，内置会话上下文压缩（Compaction）、消息 Schema 校验与多智能体容错护栏。

3. RLVR / 夹具内强化学习 (Stage 5) 外部约束内化为权重

手稿倒数第二图揭示了前沿范式：Harness 不仅是推理时的护栏，更是训练时的天然奖励验证器 (Verifier)。落在夹具内的轨迹作为 good Answer 回流更新策略，夹具外作为 bad Answer 剪枝，实现外挂夹具向模型直觉的内化。
