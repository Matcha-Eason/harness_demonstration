Harness Engineering

给模型套上「夹具」的工程学

模型的输出天生是一张发散的「云」。
Harness（夹具 / 挽具）是模型之外的一切约束：它夹住每一轮输出，
把 噪声 变成 确定性，把 幻觉 变成 可生产的结果。

  • 白板从「理想中的 LLM」画起，一步步逼出 Harness Engineering 这个概念。
  • 核心隐喻是制造业的 夹具（fixture / clamp）：不改变工件（模型）本身，只约束它的作用范围。
  • 业界同义词：agent harness / scaffolding / guardrails —— 模型之外的那层工程外壳。
  • 要解决的问题只有一个：输出的 发散，会沿着「信息空间 × 交互时间」不断长大。
01 · NAIVE VIEW

1朴素想象：一条细线般的输出

  • 我们默认的世界：明确的建议（清晰的指令）＋ 强大的模型。
  • 于是 User Input 经过 LLM，应该得到一条窄窄的、几乎确定的输出（图上那根细条）。
  • 但这只是理想态：它把「输出空间」想象成了一个点。
白板原话：明确的建议、强大的模型 → output（细线）。
02 · REALITY

2现实：输出是一团发散的云

  • ① 难的问题 → 解法链条又长又细，输出空间自然展开。
  • ② 弱的模型 → 过多 slots（要模型自己填的空位）、噪声。
  • ③ 工具、信息的缺失 → 过大幻觉、噪声。
  • 三者任一成立，输出就从「细线」膨胀成「云」：同一个 input，落在云里任何一点都有可能。
slots ≈ 模型必须自行猜测的填空位：空位越多，方差越大。
03 · COORDINATES

3坐标：发散在两个维度上生长

  • 纵轴 · 信息空间：一次输出要承载多少信息？空间越大，可偏离的方向越多。
  • 横轴 · 交互时间：对话 / Agent 跑多少轮？轮数越多，偏差越有机会累积。
  • 所以「管住输出」不是一次性的动作，而是一个二维持续过程。
  • 后面所有的夹具设计，都可以放回这个坐标系里检验：它压缩的是哪一维？
04 · HARNESS ENGINEERING

4Harness：在出口处装上夹具

  • output → 被 Harness 限制：减少 slots、噪声、发散。
  • 夹具不改造模型，只约束出口的截面：发散的云被夹成一条能用的流。
  • 落到工程上，夹具 = 提示结构、工具与权限边界、schema / 格式校验、检索注入、流程编排……的总和。
  • 注意方向：夹具夹的是 output；而被夹住的结果，又会成为下一轮的 input（见下页）。
业界对照：Anthropic 称之为 agent harness —— 系统提示、工具、上下文管理、环境管理组成的外壳；模型换代，harness 复用。
05 · MULTI-TURN

5多轮：噪声会复利，夹具要每轮都在

  • 上一轮的 output 就是下一轮的 new input：LLM → output → LLM → ……
  • 更复杂的 input 导致更噪声的 output，逐轮扩大 —— 噪声是复利，不是加法。
  • real output：被夹住。真正流进下一轮的，只应该是夹具之内的那部分。
  • 工程对应：上下文压缩（compaction）、状态外置（git / 进度文件 / 结构化清单）、每轮出口校验 —— 都是「轮间夹具」。
06 · RL LOOP

6闭环：夹具内外，就是奖励信号

  • 夹具天然是判定器：答案落在夹具内 = good，夹具外 = bad。
  • 于是「夹住 / 没夹住」可以直接当作奖励信号：学习、多轮迭代（RLHF / 拒绝采样 / 自我修正同构）。
  • 生产化 Agent、决策 module：harness 从「拦截器」升级成「训练器 + 决策外壳」。
  • 关键点：先有夹具，才有可学习的信号 —— 约束产生数据。
07 · PRODUCTION

7极强的夹具力度 → 生产确定性

  • 把夹具拧到最紧：输出通道只剩一条缝 —— 生产确定性。
  • 如 AgentScope、LangGraph：把夹具固化为编排框架（图 / 状态机 / 管道）。
  • 这是一条力度光谱：全自由 agent ←→ 强夹具 workflow；场景风险决定拧多紧。
  • 代价要认清：夹具越紧，灵活性越低 —— harness engineering 的本质是约束的定价。

TAKEAWAY

一句话带走

模型决定上限，
Harness 决定下限。
Harness Engineering = 设计夹具力度：

  • 让每一轮输出被夹住才放行；
  • 让夹具内 / 外成为可学习的信号；
  • 让「确定性」成为生产环境里可调节、可定价的工程变量。
